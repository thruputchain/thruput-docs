Get a working result on Devnet. Choose the tools you want to use; you do not need to follow every path.

## Choose your path

- **[CLI quickstart](/get-started/cli/):** create a wallet, request test funds, and inspect a transaction.
- **[Contract quickstart](/get-started/contract/):** build and test a counter, deploy it to Devnet, and read its updated value.
- **[TypeScript quickstart](/get-started/typescript/):** read an existing contract from a small script. No Rust or wallet required.
- **[React quickstart](/get-started/react/):** display contract data and refresh it from an interface. No contract deployment required.

## Work with a coding agent

[Build with an Agent](/start/build-with-an-agent/) gives you one prompt to install the tools, fund a wallet, and deploy and call a counter on Devnet. For a smaller task, use the prompt in an individual quickstart.

## What you need

CLI and contract work use the [Thruput CLI and Cargo registry](/cli/install/). TypeScript and React applications use [Node.js and GitHub Packages](/typescript/setup/). Install the latest releases; the quickstarts link to the setup they need.

Devnet is a shared test network and can be reset. Keep your development keys, but expect to request new test funds or redeploy after a reset.

## Build a complete application

Follow the four-part [Build a counter](/tutorials/build-a-counter/) guide from contract to TypeScript, React, and a wallet-approved update. Each part builds on the project from the previous part.

For token and AMM contract projects, see [Guides](/guides/). New to the platform? Read the [Introduction](/architecture/) before choosing a path.
