## Delivery and remaining boundaries

- CLI 0.17.0 embeds developer-site snapshot `2942cda8f09fd71b31dc60803e0e0a3d132f446b` with guide 0.16.0-rc.1. Website changes cannot update that immutable binary. After these docs are reviewed and published, select a fresh snapshot in the next CLI release. In the meantime, `groundhog --skill` already provides the installed 0.17.0 guidance.
- The updated guide is copied byte-for-byte from the released CLI source and matches the real `groundhog --skill` output. The previous versioned guide is preserved.
- Linux ran under x86-64 emulation on an ARM64 host. Pristine Ubuntu 26.04.1 installed the documented prerequisites, but archive extraction hit an unsupported syscall. Host extraction bypassed that boundary; subsequent tests used an existing Ubuntu qualification image with a fresh July toolchain and empty crate cache. Deployment used the same platform-neutral RV32 artifact tested on macOS. Native x86-64 archive extraction and a fully pristine Linux installation remain unverified. All task containers were removed.
- Authenticated package downloads were tested with existing account permissions. Provisioning a new participant's GitHub/Cargo access was not exercised.
- The browser extension wallet flow was source/type checked, not executed with an installed wallet extension. Other-chain illustrative snippets were not compiled against those ecosystems' SDKs.
- The swap tutorial was checked against current example source and pinned execution semantics. The full swap application was not deployed in this rehearsal.
- Distributed consensus, host replacement and long-running persistence were outside this documentation audit.
