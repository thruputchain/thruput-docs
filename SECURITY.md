# Security policy

Report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/thruputchain/thruput-docs/security/advisories/new).
Include the affected page or commit, reproduction steps, and expected impact.
Keep signing keys, access tokens, and personal data out of reports.

This repository contains the Thruput website, documentation, and offline
documentation build tools. Reports for these components should use this
repository. For vulnerabilities in a CLI, SDK, wallet, or node, use that
component's security policy.

Fixes target the current default branch. Use
[public issues](https://github.com/thruputchain/thruput-docs/issues) for ordinary
documentation errors and support questions.
